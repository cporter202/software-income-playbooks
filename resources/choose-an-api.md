# How To Pick An API

The right API is not the one with the most endpoints. It is the one that makes it easiest to sell a useful output.

## Good Commercial Signs

- The data maps directly to a business workflow
- A buyer can understand the value without technical explanation
- The output can power reports, alerts, enrichment, or automation
- The first paid use case is narrow and obvious
- You can ship a visible result in days, not months

## Weak Signs

- Interesting data with no clear buyer
- Too much cleanup needed before the output is useful
- Hard-to-explain value proposition
- Expensive infrastructure before customer validation
- A crowded market with no angle or wedge

## The Fast Filter

Ask these questions before adding any API to the curated list:

1. What specific customer would pay for this output?
2. What is the smallest paid workflow it unlocks?
3. Can a service version be sold before full software exists?
4. Does it create recurring value or only one-off curiosity?
5. Is there a cleaner wedge than "all-in-one dashboard"?

## Strong First Wedges

- Weekly monitoring
- Prospect list generation
- Review and sentiment analysis
- Competitor tracking
- Alerting for new opportunities
- Enrichment for an existing sales or ops workflow
