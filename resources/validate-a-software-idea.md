# How To Validate An Idea

Validation should reduce uncertainty, not create paperwork.

## What To Validate First

- Is the pain real?
- Is the buyer easy to identify?
- Can you describe the output in one sentence?
- Would someone pay for a manual version now?

## Fast Validation Methods

- Build a sample report from live API data and ask for feedback
- Sell a done-for-you version before building software
- Post a narrow offer in founder, operator, or niche communities
- Run cold outreach with a concrete before/after promise
- Interview five buyers from the same niche, not five random people

## Red Flags

- "Everyone could use this"
- No one asks what it costs
- Buyers like the concept but not the workflow
- The API output looks impressive but does not change a decision

## The Minimum Proof You Want

- A clear niche
- A repeatable use case
- At least a few conversations with active pain
- One signal that someone would pay or pilot
