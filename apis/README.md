## Selection Lens

- Short path from API output to a paid outcome
- Useful for a specific customer, not just a general-purpose dataset
- Feeds a workflow someone would pay to automate, monitor, or improve
- Supports repeatable deliverables, subscriptions, or clear one-time service packages

## Best Monetization Paths

- Start with a done-for-you report or audit
- Turn repeated analysis into monitoring and alerting
- Productize the workflow once one niche keeps paying for the same output
- Prefer narrow pain and believable outcomes over giant all-in-one dashboards
