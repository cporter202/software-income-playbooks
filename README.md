# Software Income Playbooks

Curated software business playbooks built around APIs that can help you launch revenue-producing products, automations, services, and internal tools faster.

This repo is intentionally opinionated. It does not try to list every API on the internet. It focuses on APIs that are useful for building something people will actually pay for.

## What This Repo Helps You Answer

- What software can I build with a real path to revenue?
- Which customer has the pain and budget?
- Which APIs are strong enough to build on?
- What is the simplest MVP?
- How could I monetize it?
- How hard is it to build?
- How fast could I launch?

## Who This Is For

- Indie hackers looking for practical product ideas
- Agencies packaging repeatable service offers
- Automation builders selling workflows and internal tools
- SaaS founders looking for narrower, faster-to-launch opportunities
- Developers who want a more commercial lens on API discovery

## How To Use This Repo

1. Start with a category in [categories/README.md](./categories/README.md) if you already know the market.
2. Browse [playbooks/README.md](./playbooks/README.md) if you want concrete product or service ideas.
3. Review [apis/README.md](./apis/README.md) to find strong APIs with clear commercial use.
4. Use the docs in [resources/README.md](./resources/README.md) to validate, scope, and price the opportunity.
5. Copy a starting point from [templates/README.md](./templates/README.md) when adding new entries.

## Curatorial Rules

- Fewer, better APIs over massive quantity
- Business utility beats novelty
- Practical launch speed matters
- Weak, generic, or unclear entries should stay out
- Existing affiliate links from the source repo are preserved when reused
- The repo should read like a builder asset, not a scrape dump
